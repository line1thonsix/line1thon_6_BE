[분석 규칙]
1. common: 사용자와 기준 답변이 의미상 공통으로 이해한 내용.
2. supplement: 사용자가 놓친 추가 정보. 기준 답변에 근거한 사실적으로 정확하고 검증 가능한 내용만 포함한다.
3. unique: 기준 답변에 없더라도 질문 조건에 비추어 타당한 사용자의 독창적인 관점.
4. error: 코드 조건 또는 개념과 명백하게 충돌하는 사용자 주장만 포함한다.
5. judgment_hold: 근거가 부족하거나 의미가 모호하여 판단을 보류해야 하는 내용. 명확한 오류로 단정하지 않는다.
6. 다섯 분류는 모두 배열이다. 해당 항목이 없으면 빈 배열 []을 반환한다.
7. 모든 항목에 짧고 명확한 title을 포함한다.
8. user_quote는 <USER_THOUGHT> 안에 실제 존재하는 연속 문자열만 그대로 인용한다. 문장을 만들거나 요약해 인용하지 않는다.
9. supplement와 judgment_hold 모두 특정 사용자 발언을 직접 인용할 수 없으면 user_quote를 빈 문자열("")로 둔다. 두 분류 모두 빈 인용을 허용한다.
10. 사용자 발언이 아닌 AI 보충 설명을 사용자 발언처럼 표현하지 않는다.
11. 각 분류의 근거와 설명을 간결하고 구체적으로 작성한다.
12. 사용자의 이해도나 노력에 점수·등급을 부여하지 않는다.
13. 기준 답변 자체가 틀렸을 가능성이나 정보 부족이 있으면 단정하지 말고 judgment_hold로 다룬다.
14. 사용자에게 없는 수정 코드나 해결책을 사용자 고유 관점으로 추론하지 않는다.
